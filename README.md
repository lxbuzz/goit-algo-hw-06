# GOIT Homework # 06 — Address Book (OOP)

This project implements an address book using OOP principles.

## Features

### AddressBook
- Add records
- Find record by name
- Delete record
- Pretty string output

### Record
- Store name and multiple phones
- Add phone
- Remove phone
- Edit phone
- Find phone

### Phone
- Validation: must contain exactly 10 digits

## How to run

```bash
python3 main.py
